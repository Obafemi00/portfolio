# Project instructions for Claude Code

## Git commits and pull requests

Do not add any attribution footers to commit messages or pull request bodies. Specifically, do not add:

- Co-Authored-By lines
- Claude-Session lines
- "Generated with Claude Code" lines
- Any other line indicating AI involvement in the commit or PR

Keep commit messages focused on what changed and why. Follow conventional commit format where possible: feat:, fix:, chore:, refactor:, docs:, test:.

Keep pull request descriptions focused on the change. Include a Summary section and a Test Plan section. Do not append attribution.
